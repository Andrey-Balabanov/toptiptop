# Launch kit

Drafts for announcing TopTipTop. Nothing here is published automatically — edit,
replace `https://YOUR-DOMAIN` with the real address, add 2–3 screenshots or a short
GIF (course lesson, statistics heatmap, a race), and post them yourself.

| File | Where | Language |
|------|-------|----------|
| [habr.md](habr.md) | Habr (article, «Я пиарюсь» / «Учебный процесс в IT») | ru |
| [pikabu.md](pikabu.md) | Pikabu (short post with GIF) | ru |
| [reddit-typing.md](reddit-typing.md) | r/typing, r/learnprogramming (show-off) | en |
| [product-hunt.md](product-hunt.md) | Product Hunt listing + maker comment | en |
| [outreach.md](outreach.md) | Letters to schools, bootcamps, YouTube teachers | ru |

Suggested order: Pikabu + Reddit first (quick feedback, fix rough edges), Habr a
week later with real numbers, Product Hunt once the English UI is polished.
Before posting, set `PUBLIC_URL` (link previews) and, if you want numbers,
`ANALYTICS_SCRIPT_URL` — see ENV_REFERENCE.md.
