# Как я сделал бесплатный тренажёр слепой печати, который сам находит ваши слабые буквы

*Черновик статьи для Хабра. ~6 минут чтения.*

## Зачем ещё один тренажёр

Большинство тренажёров слепой печати либо платные, либо дают одни и те же упражнения
всем подряд. Я хотел тренажёр, который:

- **учит постепенно** — от домашнего ряда к цифрам, не давая перескочить вперёд;
- **подстраивается** — замечает, где именно вы ошибаетесь, и гоняет эти буквы;
- **не надоедает** — ежедневная цель, серия дней, достижения, гонки с друзьями;
- **бесплатный и без рекламы**, работает в браузере и ставится как приложение.

## Что внутри

**Пошаговый курс.** 19 уроков для русской раскладки (17 для английской): каждый добавляет
пару клавиш к уже выученным — сначала «а о», потом «в л» и так до цифр. Тексты урока
собираются из *настоящих слов*, составленных только из пройденных букв, плюс короткие
упражнения на новые клавиши. Следующий урок открывается при 95% точности и растущей
цели по скорости (от 12 до 30 WPM).

**Адаптивные уроки.** Тренажёр считает попадания и промахи по каждой букве. Режим
«Адаптивно: слабые буквы» берёт буквы, на которых вы ошибаетесь заметно чаще своего
среднего, и строит урок из слов, где их много. Карта ошибок в «Статистике» показывает
клавиатуру, раскрашенную от зелёного к красному.

**Подсказки для пальцев.** Каждая клавиша окрашена в цвет пальца, следующая клавиша
подсвечивается, а анимированная стрелка показывает, куда двинуть палец от домашнего
ряда. Строка над клавиатурой держит курсор в центре — не нужно бегать глазами по экрану.

**Чтобы возвращаться каждый день.** Дневная цель (сколько текстов в день), серия дней,
33 достижения (два секретных), уровни и XP.

**С друзьями.** Группы с приватной таблицей лидеров (удобно для класса — создатель видит
точность и активность каждого), испытание недели — один текст для всех, и гонки в
реальном времени по коду комнаты.

## Немного о технике

- Node.js + Express + SQLite (better-sqlite3), фронтенд — чистый JS-модулями, без фреймворка.
- Скорость и XP считаются в браузере, поэтому сервер **перепроверяет** каждую сессию:
  пересчитывает WPM по длине текста и времени, отклоняет нечеловеческие результаты
  (>260 WPM) и ограничивает XP максимумом, возможным при идеальном прохождении.
- Гонки живут в памяти сервера, браузеры опрашивают комнату раз в секунду; позиция не
  может «прыгнуть» быстрее, чем позволяет прошедшее время.
- PWA: манифест + service worker (network-first, чтобы деплой никогда не отдавал
  устаревшие файлы), работает офлайн.
- 330+ тестов на Jest, прогоняются в GitHub Actions на каждый push.
