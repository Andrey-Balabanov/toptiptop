## Maker's first comment

Hi Product Hunt! 👋

I built TopTipTop because typing trainers either cost money or give everyone the same drills.
This one watches *where* you make mistakes and builds lessons from real words heavy in those letters.

A few details I'm proud of:
- course texts only use real words made of the keys you've learned so far;
- the server re-checks every result, so the leaderboards stay honest;
- groups with a private leaderboard — handy for a class or a team.

It's free and ad-free. I'd love to hear what would make you practise every day — and what speed you're at!
