# 🖥️ Как запустить TopTipTop локально

Пошаговая инструкция для **новичков**. Если вы никогда не запускали сервер — не страшно, всё объяснено.

---

## 📋 Что вам понадобится

| Что нужно | Зачем |
|-----------|-------|
| Компьютер (Windows / macOS / Linux) | Для запуска сервера |
| **Node.js** (версия 18 или новее) | JavaScript-движок, на котором работает проект |
| **Браузер** (Chrome, Edge, Firefox) | Чтобы открыть тренажёр |
| **Терминал** (командная строка) | Чтобы вводить команды |

> 💡 **Терминал** на Windows — это «Командная строка» (cmd), PowerShell или Git Bash.  
> На macOS — «Терминал». На Linux — любой эмулятор терминала.

---

## ✅ Шаг 1. Установка Node.js

1. Откройте сайт: [https://nodejs.org](https://nodejs.org)
2. Скачайте **LTS-версию** (рекомендованную, самую стабильную)
3. Запустите установщик и нажимайте «Далее» / «Next» — ничего не меняйте
4. **Проверьте установку**: откройте **терминал** и введите:

```bash
node --version
```

Если вы видите что-то вроде `v18.x.x` или `v20.x.x` — Node.js установлен ✅

---

## 📦 Шаг 2. Скачать проект

Есть два способа:

### Вариант A: Скачать ZIP-архив (проще)

1. Перейдите на страницу проекта (например, GitHub)
2. Нажмите кнопку **«Code»** → **«Download ZIP»**
3. Распакуйте архив в удобную папку (например, `C:\projects\toptiptop` или `~/Desktop/toptiptop`)

### Вариант B: Скачать через Git (продвинутый)

```bash
git clone https://github.com/ВАШ_ЛОГИН/toptiptop.git
cd toptiptop
```

## 📁 Шаг 3. Структура проекта (чтобы вы ориентировались)

```
toptiptop/
├── server.js          ← 📌 Главный файл сервера (запускает приложение)
├── package.json       ← Список зависимостей
├── .env               ← Настройки (порт, секретный ключ)
├── src/
│   ├── config.js      ← Читает настройки из .env
│   ├── db.js          ← База данных SQLite
│   ├── routes/        ← API-маршруты
│   ├── services/      ← Логика приложения
│   └── middleware/    ← Аутентификация, проверка данных
├── public/            ← Фронтенд (HTML, JS, CSS)
└── data/              ← Папка для базы данных (создаётся автоматически)
```

## 🔧 Шаг 4. Установка зависимостей

В **терминале** перейдите в папку проекта:

```bash
# Windows
cd C:\путь\к\toptiptop

# macOS / Linux
cd ~/путь/к/toptiptop
```

Затем выполните:

```bash
npm install
```

Эта команда:
- Читает файл `package.json`
- Скачивает все нужные библиотеки (Express, SQLite, JWT и т.д.)
- Создаёт папку `node_modules` с зависимостями

> ⏳ Подождите 10–30 секунд. Если команда завершилась без красных ошибок — всё хорошо ✅

---

## ⚙️ Шаг 5. Настройка .env

В корне проекта уже есть файл **`.env`**. Откройте его в **Блокноте** (или любом текстовом редакторе).

Вы увидите:

```env
PORT=3001
JWT_SECRET=change-this-to-a-random-secret-in-production
JWT_EXPIRES_IN=7d
DB_PATH=./data/toptiptop.db
```

### Что здесь можно менять:

| Параметр | Что делает | Для новичка |
|----------|-----------|-------------|
| `PORT=3001` | На каком порту запустится сервер | **Не трогайте** — оставьте 3001 |
| `JWT_SECRET=...` | Секретный ключ для токенов | Можно оставить как есть (для локальной разработки) |
| `JWT_EXPIRES_IN=7d` | Срок действия токена (7 дней) | **Не трогайте** |
| `DB_PATH=./data/toptiptop.db` | Путь к файлу базы данных | **Не трогайте** |

> ✅ **Ничего менять не нужно** — всё уже настроено для локального запуска.

---

## 🚀 Шаг 6. Запуск сервера

В **терминале** (всё ещё в папке проекта) выполните:

```bash
npm start
```

Или (рекомендуется — автоматическая перезагрузка при изменениях):

```bash
npm run dev
```

### Что вы увидите:

```
TopTipTop server running on http://localhost:3001
```

Это значит, что сервер запущен и работает ✅

---

## 🌐 Шаг 7. Открыть в браузере

1. Откройте **браузер** (Chrome, Edge, Firefox)
2. В адресной строке введите: **http://localhost:3001**
3. Нажмите **Enter**

Вы увидите тренажёр слепой печати:
- Начните печатать — клавиши подсветятся
- Очки, уровень и достижения сохраняются в браузере
- При регистрации прогресс сохраняется на сервере

---

## ⏹️ Шаг 8. Остановка сервера

Чтобы выключить сервер, в **терминале** нажмите:

```
Ctrl + C
```

(На Windows может попросить подтвердить — нажмите `Y`)

## ❗ Частые проблемы и решения

### Проблема 1: `npm install` выдаёт ошибки

**Симптом:** Красные сообщения, ошибка с `better-sqlite3`

**Решение:** Убедитесь, что установлен Node.js 18+. Попробуйте:

```bash
node --version   # должно быть 18.x.x или выше
```

Если Node.js старый — скачайте новый с [nodejs.org](https://nodejs.org)

### Проблема 2: `npm start` — ошибка «port is already in use»

**Симптом:** Не удаётся запустить, порт занят

**Решение:** Скорее всего, сервер уже запущен в другом окне терминала. Закройте его, либо смените порт в `.env`:

```env
PORT=3002
```

### Проблема 3: «Cannot find module» при запуске

**Симптом:** Ошибка вида `Error: Cannot find module 'express'`

**Решение:** Забыли установить зависимости. Выполните:

```bash
npm install
```

### Проблема 4: Пустая страница в браузере / ошибка 404

**Симптом:** В браузере белый экран или «Not Found»

**Решение:**
1. Проверьте, что сервер запущен (должно быть сообщение в терминале)
2. Проверьте, открыли ли вы правильный адрес: **http://localhost:3001**
3. Проверьте, что папка `public/` существует и содержит `index.html`

### Проблема 5: Не видно картинок/стилей

**Симптом:** Текст есть, но стили не применяются

**Решение:** Убедитесь, что папка `public/` содержит папки `css/` и `js/` с файлами. Очистите кэш браузера (`Ctrl+F5`)

### Проблема 6: База данных не создаётся

**Симптом:** Ошибка при регистрации или сохранении

**Решение:** Убедитесь, что папка `data/` существует в корне проекта. Если нет — создайте её вручную:

```bash
mkdir data
```

## ❓ Часто задаваемые вопросы

### ❔ Нужно ли подключаться к интернету?

Только чтобы **скачать проект и установить зависимости** (`npm install`).  
После этого всё работает **офлайн** — интернет не нужен.

### ❔ Где хранятся данные?

Прогресс без регистрации — в **localStorage браузера** (не очищайте его).
После регистрации — в файле **`data/toptiptop.db`** (SQLite).

### ❔ Как сбросить всё и начать заново?

1. Остановите сервер (`Ctrl+C`)
2. Удалите файл `data/toptiptop.db`
3. В браузере очистите localStorage для `localhost:3001`
4. Запустите серв заново (`npm start`)
