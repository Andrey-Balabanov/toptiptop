# 🌐 Как развернуть TopTipTop в интернете (бесплатно)

Пошаговая инструкция для **новичков** без домена и хостинга.

Мы будем использовать **Render** — бесплатный сервис, на котором можно запустить сервер.

> 🎯 **Результат:** Тренажёр будет доступен в интернете по ссылке вида `https://toptiptop.onrender.com`

---

## 📋 Что вам понадобится

| Что нужно | Зачем |
|-----------|-------|
| **GitHub аккаунт** (бесплатно) | Хранить код в облаке |
| **Render аккаунт** (бесплатно, регистрация через GitHub) | Запускать сервер в интернете |
| **Email** | Для регистрации |

> 💡 **Всё бесплатно!** Render даёт 750 часов в месяц на бесплатном тарифе — этого хватает на весь месяц.

---

## 📦 Шаг 1. Регистрируемся на GitHub

Если у вас уже есть аккаунт — пропустите этот шаг.

1. Откройте [https://github.com/signup](https://github.com/signup)
2. Введите:
   - **Email** — ваш действующий email
   - **Password** — придумайте пароль
   - **Username** — например, `vasyapupkin` (будет виден всем)
3. Подтвердите email (придёт письмо)
4. Всё готово ✅

---

## 📁 Шаг 2. Создаём репозиторий (хранилище кода)

1. Зайдите на GitHub → нажмите **+** в правом верхнем углу → **New repository**
2. Введите название: **toptiptop**
3. Выберите **Public** (чтобы Render мог прочитать код)
4. **Не ставьте** галочку «Initialize with README» — у нас уже есть свой код
5. Нажмите **Create repository**

Вы попадёте на страницу с инструкциями. **Не закрывайте её** — она понадобится на шаге 4.

---

## 🔧 Шаг 3. Готовим проект к загрузке

### 3.1. Открываем .env и меняем настройки

Найдите файл `.env` в папке проекта и откройте его **Блокнотом**.

**Замените содержимое на это:**

```env
JWT_SECRET=случайный-длинный-секретный-ключ
JWT_EXPIRES_IN=7d
DB_PATH=./data/toptiptop.db
```

> ⚠️ **Удалите строку `PORT=3001`!** Render сам назначает порт через переменную окружения. Сервер уже умеет его читать (`config.js` берёт `process.env.PORT`).

> 🔐 **JWT_SECRET** придумайте свой — например: `mySecretKeyTopTipTop2024` (чем длиннее и случайнее, тем лучше)

### 3.2. Создаём .gitignore

В папке проекта создайте файл с именем **`.gitignore`** (без расширения, точка в начале).

Откройте его в Блокноте и вставьте:

```
node_modules/
.env
data/
*.db
.DS_Store
```

Этот файл говорит Git: «не загружай эти папки и файлы на сервер».

## ⬆️ Шаг 4. Загружаем код на GitHub

### 4.1. Открываем терминал

- **Windows**: `Win + R` → `cmd` → Enter
- **Mac**: `Cmd + Пробел` → `Терминал` → Enter

### 4.2. Переходим в папку проекта

```bash
# Пример для Windows:
cd C:\путь\к\папке\toptiptop

# Пример для Mac:
cd ~/Desktop/toptiptop
```

### 4.3. Настраиваем Git (только первый раз)

```bash
git config --global user.name "Ваше Имя"
git config --global user.email "ваш-email@example.com"
```

### 4.4. Инициализируем Git

```bash
git init
git add .
git commit -m "Первый коммит"
```

### 4.5. Создаём токен доступа (вместо пароля)

Сейчас GitHub не принимает пароль для Git. Нужен **токен**.

1. Зайдите на GitHub → нажмите на свой аватар → **Settings**
2. В левом меню: **Developer settings** → **Personal access tokens** → **Tokens (classic)**
3. Нажмите **Generate new token (classic)**
4. Заполните:
   - **Note**: `deploy-toptiptop`
   - **Expiration**: выберите «No expiration» (или 90 дней)
   - Галочки: поставьте **repo** (все подпункты)
5. Нажмите **Generate token**
6. **Скопируйте токен** (он выглядит как `ghp_xxxxxxxxx...`) — больше вы его не увидите!
7. Вставьте токен в Блокнот, чтобы не потерять

### 4.6. Привязываем локальный репозиторий к GitHub

Замените `ВАШ-ЛОГИН` на свой логин (например, `vasyapupkin`):

```bash
git remote add origin https://github.com/ВАШ-ЛОГИН/toptiptop.git
git branch -M main
git push -u origin main
```

После этой команды Git попросит:
- **Username**: ваш логин на GitHub (например, `vasyapupkin`)
- **Password**: **не пароль, а токен!** Вставьте скопированный `ghp_...`

> 💡 Чтобы больше не вводить токен, можно настроить Git Credential Manager. Но для первого раза — вводите вручную.

**Если всё получилось** — в терминале будут строчки с `main -> main`, а на GitHub появятся файлы. ✅

## ☁️ Шаг 5. Запускаем на Render

### 5.1. Регистрируемся на Render

1. Откройте [https://render.com](https://render.com)
2. Нажмите **Sign up with GitHub** (синяя кнопка)
3. Подтвердите доступ — Render будет видеть ваши репозитории
4. Готово ✅

### 5.2. Создаём Web Service

1. На главной странице Render нажмите кнопку **New +** → **Web Service**
2. Выберите репозиторий **toptiptop**
3. Настройте:
   - **Name**: `toptiptop` (будет частью адреса)
   - **Region**: выберите ближайший (например, Frankfurt или Ohio)
   - **Branch**: `main`
   - **Runtime**: Node
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Plan**: выберите **Free** (бесплатный)

### 5.3. Добавляем переменные окружения

Прокрутите вниз до раздела **Environment Variables**.
Нажмите **Add Environment Variable** и добавьте:

| Key | Value |
|-----|-------|
| `JWT_SECRET` | такой же, как в вашем `.env` (или новый) |
| `JWT_EXPIRES_IN` | `7d` |
| `DB_PATH` | `./data/toptiptop.db` |

> **Не добавляйте `PORT`** — Render устанавливает его автоматически.

### 5.4. Нажимаем Create Web Service

Render начнёт сборку и запуск. Это займёт **2–5 минут**.

После завершения вы увидите ссылку:
```
https://toptiptop.onrender.com
```

Откройте её в браузере — тренажёр работает в интернете! 🎉

## ⚠️ Особенности бесплатного тарифа

### 🥶 Режим сна (Spindown)

Render **выключает** бесплатный сервер, если к нему не обращались **15 минут**.

- Когда вы откроете сайт после простоя — придётся подождать **30–50 секунд**, пока сервер проснётся
- Это нормально для бесплатного тарифа
- Если хотите, чтобы сервер не засыпал — нужно платить ($7/мес)

### 💾 База данных на бесплатном тарифе

Файл SQLite хранится прямо на сервере. На бесплатном тарифе Render:

- **Пересоздаёт** сервер при каждом деплое (новая версия)
- База данных **сбрасывается** при перезапуске!

**Что это значит:** Зарегистрированные пользователи и их результаты **пропадут** при следующем деплое.

### 🛠️ Как сохранять данные (продвинуто)

Чтобы данные не пропадали, нужно подключить облачную базу. Бесплатные варианты:

1. **Supabase** (PostgreSQL) — [https://supabase.com](https://supabase.com)
2. **MongoDB Atlas** (Free Tier) — [https://www.mongodb.com/atlas](https://www.mongodb.com/atlas)

> Но для этого придётся переписать `src/db.js` — сейчас он использует SQLite. Для новичка: оставьте как есть, просто знайте про это ограничение.

## ❓ Часто задаваемые вопросы

### ❔ Сколько стоит?

**$0.** Регистрация, хостинг, домен — всё бесплатно.

### ❔ Как долго работает бесплатный сервер?

Render даёт **750 часов в месяц** — это 24/7 в течение 31 дня. Если не превышать — хватит на месяц.

### ❔ Почему сайт долго загружается?

Из-за режима сна (см. выше). После 15 минут бездействия Render выключает сервер. При первом заходе нужно 30–50 секунд на пробуждение.

### ❔ URL некрасивый, можно свой домен?

Можно, но это платно. Render даёт бесплатный поддомен `*.onrender.com`.  
Чтобы подключить свой домен (`печать-тренажёр.рф`), нужно купить домен у регистратора и настроить DNS. Это стоит от 200–500 руб/год.

### ❔ Что если я сломаю приложение?

Ничего страшного! Render хранит историю деплоев. Можно откатиться на предыдущую рабочую версию в панели управления: **Dashboard** → **Deploy History** → **Rollback**.

### ❔ Нужно ли ставить антивирус или брандмауэр?

Нет. HTTPS (шифрование) уже настроен Render автоматически. Для бесплатного тренажёра больше ничего не нужно.
